## 6. Термины и сокращения

- **COM** — Component Object Model, интерфейс объектов Windows; здесь использован только для чтения Task Scheduler.
- **XML** — Extensible Markup Language, формат определения задачи.
- **Writer / нормализатор** — функция формирования ожидаемого определения / функция сопоставления разрешённых эквивалентных представлений.
- **EOF** — конец потока; **SHA-256** — криптографическая контрольная сумма.
- **Source52 / Product** — отдельно закреплённые исходники / установленный или подготовленный продукт; наблюдение задачи не связывает их автоматически.
- **OBSERVED_INSTALLED / CLOSED** — наблюдено установленное состояние / завершены исходные ресурсы этого наблюдения.
- **Create/Export roundtrip** — создание задачи и обратное получение её определения.
