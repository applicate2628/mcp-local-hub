## 1. Установленный результат

В #660, коммит `58d7c948e410fdb5969abb9a8a4febfea8f14150`, закрыта наблюдавшаяся граница `errnoIs → Unwrap` для точного Windows SDK; последующий nil-callback reader также прослежен контекстно. Отказ для неизвестных целей и прежние бюджеты анализа сохранены. Производственный барьер и различающие фикстуры прошли как в композиции, так и на собственной базе #660.

В weekly-транзакции и `SchedulerUpgrade` установлен отказ разрушительной замены существующего поколения без исключительного права записи. Проверены внешняя замена, одинаковое XML-представление разных поколений и неопределённый результат создания. XML — расширяемый язык разметки, здесь формат определения задачи; равенство XML не удостоверяет поколение.

В отдельном #669, коммит `ec2248643d875390c41b519b85424a5ca0ce90d1`, исправлен B1: ошибка освобождения recovery-блокировки сохраняется, повторный захват после неподтверждённого освобождения отклоняется, исходная и восстановительная причины проходят через публичную оболочку. Матрица исходов и два отрицательных контроля пройдены.

Из прежнего Source `4c3eb47d002ea729fe80370a75506a1d0c9650ac` фактически подготовлены и различены обычный Product, Product #657 и издатель Serena. Они не содержат новые изменения #660, #663 и #669. Подробные квитанции и точные хеши находятся в [основном отчёте](README.md).

## 4. C — измерения и Rust

1. Relay и CMake: настоящие потребители на одинаковых входах; пиковая и удерживаемая память, параллельность, распределения задержек, отмена и потери.
2. Relay: возобновление потока, начатого HTTP POST; повтор операции с неизвестным эффектом не считать восстановлением. HTTP — протокол передачи данных; POST — метод запроса, способный создавать эффект на сервере.
3. Rust: выбрать настоящего Go-потребителя, проверить межъязыковую границу и подтвердить измеримую пользу либо отдельное продуктовое требование.
4. Reader #627: ошибки метаданных, закрытия и их сочетания; затем настоящий адаптер с сохранением контрактов Go.
5. a217: продолжить ревью по сохранённым 64 точным файлам; отдельно установить применимость следующих ветвей и продуктового потребителя.
