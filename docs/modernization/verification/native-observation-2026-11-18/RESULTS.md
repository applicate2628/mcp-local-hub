## 1. Область и среда

Измеряются время создания и размер рабочего набора собственного тестового процесса. В первом варианте две существующие вспомогательные функции Go открывают процесс раздельно; во втором оба поля читаются за одно открытие; в третьем дескриптор уже удерживается. Приобретение удерживаемого дескриптора находится вне таймера. Это диагностическое чтение, не полномочие управления процессом.

Среда: Windows build **22631**, amd64, **Intel(R) Core(TM) i5-10400 CPU @ 2.90GHz**, **go version go1.27.4 windows/amd64**. `GOMAXPROCS=4` ограничивает число одновременно исполняющих Go-код потоков; нагрузка последовательная, без `RunParallel`. Оба PR измерялись последовательно. Измерительные процессы работали без детектора гонок и профилировщика; функциональные проверки с `-race` выполнены отдельно.

Использованы установленные инструменты и существующие локальные кеши, `GOPROXY=off`, `GOSUMDB=off`, `GOVCS=*:off`, `GOTOOLCHAIN=local`, `GOENV=off`, `GOWORK=off`, `-mod=readonly`. Все временные данные размещены в отдельной разрешённой области. Установки, изменение политик, запуск провайдеров/моделей и ручной CI (непрерывной интеграции) не выполнялись.

**Таблица 2. Медиана десяти образцов и полный наблюдавшийся диапазон. Время: нс/операцию.**

| Два существующих открытия | 3175.500 | 3158.000–3213.000 | 104.0 | 2.0 |

| Удерживаемый дескриптор | 564.150 | 559.200–581.200 | 104.0 | 2.0 |

`ns/op` — наносекунд на одну операцию; 1 мс = 1 000 000 нс. `B/op` — выделенных байтов на операцию; `allocs/op` — число выделений памяти на операцию. Медиана вычислена из всех десяти значений, а диапазон — из их минимума и максимума. Это описательные статистики, без заявления доверительного интервала или производственного выигрыша.

Исторические числа в PR получены на другой машине/версии инструментов и не служат сравнением «до/после» с этой серией. Здесь сохранена самостоятельная исходная выборка; Rust-ускорение и ускорение всего Hub не измерены.

## 4. Артефакты и воспроизведение

- [logs.zip](logs.zip) — 14 файлов: исходные стандартный вывод и вывод ошибок (stdout/stderr) всех шести команд, `receipt.json` с точными аргументами/кодами возврата/средой и `summary.json` с полными агрегатами.
- [manifest.json](manifest.json) — SHA-256 (Secure Hash Algorithm, 256-битные контрольные суммы) каждой записи и архива; опубликованные байты совпадают с исходными, редактирования логов не было.
- [SHA256SUMS](SHA256SUMS) — контрольные суммы публикуемых файлов.

Откройте чистую копию указанного исходного коммита. Направьте временные каталоги и домашние каталоги тестов в новую разрешённую область, а `GOROOT`, `GOCACHE`, `GOMODCACHE` — на проверенные существующие инструменты/кеши. Не используйте установленный Hub как тестовый образ. Точные команды из `receipt.json`:

```powershell
& 'go' 'version'
& 'go' 'env' '-json' 'GOOS' 'GOARCH' 'GOVERSION' 'CGO_ENABLED'
& 'go' 'test' '-mod=readonly' '-json' '-race' '-count=3' '-p=1' '-timeout=120s' '-run' '^TestNativeObservation(MatchesSelfCreation|FailureIsNotAbsent)$' './internal/process'
& 'go' 'vet' '-mod=readonly' '-p=1' './internal/process'
& 'go' 'test' '-mod=readonly' '-run' '^$' '-p=1' '-timeout=5m' '-benchmem' '-bench' '^BenchmarkNativeProcessObservation$' '-benchtime=1x' '-count=1' './internal/process'
& 'go' 'test' '-mod=readonly' '-run' '^$' '-p=1' '-timeout=5m' '-benchmem' '-bench' '^BenchmarkNativeProcessObservation$' '-benchtime=1s' '-count=10' './internal/process'
```

Для пересчёта медиан достаточно установленного Python и стандартной библиотеки; извлекать архив на диск не требуется:

```python
import collections, re, statistics, zipfile
with zipfile.ZipFile("logs.zip") as archive:
    text = archive.read("benchmark-samples.stdout.log").decode("utf-8")
samples = collections.defaultdict(list)
for name, value in re.findall(r"^(Benchmark\S+)\s+\d+\s+([0-9.]+)\s+ns/op", text, re.M):
    samples[name].append(float(value))
for name, values in samples.items():
    assert len(values) == 10
    print(name, "ns/op:", statistics.median(values), "range:", min(values), max(values))
```

При публикации медианы дополнительно пересчитаны через десятичные числа и отсортированные центральные значения; архив прочитан обратно, каждая запись сверена с исходным SHA-256. Это проверка целостности результата, не новый запуск измерения.

## 5. Ограничения и остаток

Только собственный процесс; не исследованы чужие процессы, отказы доступа, повторное использование PID (идентификатора процесса), выход процесса, множество одновременно наблюдаемых процессов и полный контракт снимка. Одинаковые 104 B/op и 2 allocs/op относятся к этим двум полям. Цена длительного удержания дескриптора и его интеграции во владельца здесь не измеряется.

Следующие необходимые входы: представительная нагрузка, применимые нативные сценарии отказа, данные других платформ и независимое сравнение реализаций. Сопоставление #624, #628 и изменённых путей #626 не обнаружило полного поглощения их самостоятельного кода/доказательств; оснований закрывать эти PR как дубликаты нет.

PR остаётся Draft (черновиком). Полные обязательные проверки и независимая безопасностная приёмка не объявлены пройденными; слияния PR и интеграция веток не выполнялись.

**Обозначения:** JSON — JavaScript Object Notation, текстовый формат представления данных; PASS — проверка прошла, FAIL — отказ проверки, SKIP — пропуск. receipt.json содержит запись фактического выполнения, summary.json — вычисленную сводку.
