## 6. Термины и сокращения

PR — запрос на включение изменений; Draft — черновик. HEAD — текущая вершина ветки. FFI — интерфейс между языками. PID — числовой идентификатор процесса. PATH — список каталогов поиска программ. SSE — поток событий сервера. LSP — протокол языкового сервера. COMMENTED — отправленный отзыв без одобрения; APPROVED — одобрение; CHANGES_REQUESTED — запрос исправлений. Хеши в этом отчёте — идентификаторы коммитов Git.
