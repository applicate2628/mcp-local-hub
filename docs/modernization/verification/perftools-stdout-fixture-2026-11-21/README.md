# Stdout-фикстура без побочных эффектов обнаружения oneAPI

Изменены два файла владельца `internal/perftools`: общий запуск с явно переданной средой выделен в приватную функцию, а тест ограничения stdout использует её с текущей тестовой средой. Производственный вызов по-прежнему получает `oneapi.EnvOverlay()` один раз. Проверка выполнена на существующем закреплённом MSYS Bash; весь набор `perftools` и работа с установленной oneAPI не квалифицированы.

## 1. Причина и минимальное изменение

Прежний `TestRunCaptureLimited_EnforcesStdoutLimit` запускал `bash -lc` только для вывода десяти байт. Login shell могла прочитать профиль до выполнения `printf`. Кроме того, вызов общего `runCaptureLimited` сначала обращался к `oneapi.EnvOverlay`, что на соответствующем компьютере могло запустить установленный `setvars`.

Первый рассмотренный вариант подменял обнаружение oneAPI. Он отклонён при ревью: `sync.Once` запоминал отсутствие oneAPI на весь тестовый процесс, а восстановление seam не восстанавливало кэш. Такой вариант менял условия последующих интеграционных тестов.

Окончательное изменение сохраняет один владелец выполнения: `runCaptureLimitedWithEnv` получает среду параметром и содержит прежний запуск, обработку ошибок и ограничения вывода. `runCaptureLimited` передаёт ему результат единственного `oneapi.EnvOverlay()`. При `nil` остаётся обычное наследование среды; непустая среда передаётся команде явно. Код от `cmd.Dir` до возврата результата сохранён побайтно.

Тест очищает `BASH_ENV` и `ENV` через `t.Setenv`, передаёт `os.Environ()` и запускает ровно:

```text
bash -p -c "printf '1234567890'"
```

Исходный оракул сохранён: десять байт stdout должны превысить предел пять байт и вернуть `errOutputLimitExceeded`; предел stderr — 1 024 байта. Отсутствие Bash по-прежнему даёт существующий Skip; на квалифицированном входе этот Skip не произошёл. Новых зависимостей, публичного API или изменяемого глобального test seam нет.

## 3. Свидетельства и ограничения

[shell-evidence.zip](shell-evidence.zip): **143 358 байт**, SHA-256 **`e11cfb6d56941b3f5628bda6f1a2a39062499c97edcecf2bcf00585c3a8bf74d`**. Архив содержит 196 элементов, включая `MANIFEST.json` с 195 записями. Сохранены точные кандидатные байты, manifest, исполнитель, команды, исходные результаты, потоки Go JSON, контрольные суммы и наблюдения источника. После переноса проверены CRC, состав и все размеры/SHA-256; исполняемые файлы и runtime в архив не включены.

Собственное ревью проверило сохранение производственного вызова, отсутствие вмешательства в кэш oneAPI и прежний оракул ограничения вывода. Полные default/tagged наборы Go, политика среды установленной oneAPI, настоящий CMake/Hyperfine consumer, остальные внешние программы и срок всего дерева процессов остаются непроверенными. Перенаправление среды не является системной песочницей. Внешнее ревью новой опубликованной вершины остаётся `REVIEW_PENDING`.
