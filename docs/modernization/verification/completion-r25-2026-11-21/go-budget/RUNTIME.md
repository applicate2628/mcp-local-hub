## 5. Ограничения и проверка отчёта

В свидетельстве `settled=true` относится к прямому дочернему процессу команды, `timed_out=false`, stderr имеет нулевой размер. Одновременно буквально указаны `whole_process_tree_deadline_enforced=false` и `process_tree_settlement_observed=false`. Поэтому отчёт подтверждает зафиксированное завершение прямой команды и не утверждает наблюдение завершения всего дерева процессов. В прочитанном выбранном тестовом пути не было запланировано собственных дочерних процессов; этот обзор исходников не превращается в операционную гарантию дерева процессов.

Самостоятельная проверка отчёта выполнена: исходный stdout побайтно совпал с хешем оригинального свидетельства; reducer получил все 190 фаз без дублей, недостающих имён, отказов или пропусков; время пакета и root взято из разных событий; внешнее время взято из runner; доля записи рассчитана только относительно суммы инструментированных интервалов. Наносекундная единица данных не приписана физической точности часов.

Результат поддерживает дальнейшее рассмотрение стоимости **подготовки невалидных файловых входов именно этой mutation table**. Он не даёт основания ослаблять надёжность production-записи, объявлять весь Go-набор успешным или масштабировать 30 записей на 3437 корневых API-тестов и 1960 корневых CLI-тестов. Исторические FAIL и требования нативной квалификации current #637 остаются отдельными выводами подготовительного отчёта.

JSON — JavaScript Object Notation, формат структурированных данных. CLI — command-line interface, интерфейс командной строки. API — application programming interface, программный интерфейс. UTC — всемирное координированное время. SHA-256 связывает точные байты файлов; подтверждение исполнения требует сохранённых свидетельств процесса.
