# Критерии приёмки текущего среза

Код `ba17867125b3728fb734e90b383639a3ff9175ee`. Счётчики тестов и исходные квитанции приведены в [результатах](RESULTS.md) и [сводке](execution-summary.json).

**Таблица 1 — требования, проверка и граница.**

| Требование | Подтверждение | Область вывода |
| --- | --- | --- |
| После успешного Delete и отказа Create прежнее определение не теряется только из-за отсутствия текущего обработчика отката | Случай `CurrentTaskRecovery/restored`, защищённый снимок и одно восстановление | Модельный Scheduler + реальная запись файла на Windows |
| Появившаяся задача не удаляется новым восстановлением | Случаи `external_occupant`, `create_applied_reply_lost`; отдельный нативный конфликт | Только новая ветвь текущего отказа; старые откаты других задач остаются отдельно |
| Обе причины ошибки доступны программно | `errors.Is` для исходного отказа и восстановления | Ошибка программного интерфейса установщика, не все каналы CLI |
| Неопределённый ответ восстановления не выдаётся за успех | `restore_applied_reply_lost`; потеря ответа/нулевой результат Windows-моста | Нет автоматического повтора или удаления |
| Снимок существует до удаления | `RecoverySnapshotBeforeDelete`, включая отказ Delete | Файл синхронизирован и прочитан с проверкой суммы; испытаний потери питания нет |
| Недоступность хранилища останавливает замену | `RecoverySnapshotFailureStopsReplacement` | Ни Delete, ни Create не выполняются |
| Существующий файл снимка не перезаписывается | `SaveInstallTaskSnapshotRefusesExistingFile` | Проверено значение created=false и сохранность прежних байтов |
| Сохраняются исходные байты, включая кодировку | UTF-8/UTF-16LE случаи и SHA-256 | Сохранённый JSON; нормализация XML сервисом — отдельное свойство |
| Размер сериализованного файла ограничен | Проверка пустого, превышенного и увеличенного Base64 размера | Один мебибайт полного файла |
| Поддержка безопасного восстановления проверяется до удаления | `RecoveryCapabilityRequired` | Старый основной интерфейс Scheduler не расширен |
| Прежний откат не попадает в текущую задачу через повтор имени | `RejectsAliasedRecoveryNames`: exact/case/root-prefix | Эти варианты; все Unicode-правила Windows не доказаны |
| Нативная операция создаёт без замещения | TASK_CREATE без TASK_UPDATE; тесты параметров и нативные наблюдения | Договор Microsoft и конкретный испытанный Windows-хост |
| Фактические байты опубликованного коммита повторно проверены | Точный чистый опубликованный коммит: 42 тестовых + 1 пакетный PASS для установки и 42 + 1 для Windows-моста, без FAIL/SKIP | Ровно девять файлов и один родитель |

Сохранены также прежние проверки допуска снимка, отказа удаления, создания при подтверждённом отсутствии и разделения создания/запуска. Полные наборы API/CLI/Job, установленный продукт, все владельцы, права и триггеры не относятся к этой приёмке.
