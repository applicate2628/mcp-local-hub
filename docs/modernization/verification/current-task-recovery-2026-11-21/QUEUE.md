## Термины и сокращения

- **PR (pull request)** — запрос на включение изменений. **Draft** — черновой статус запроса.
- **SHA** — идентификатор Git-объекта; **SHA-256** — контрольная сумма содержимого.
- **XML (Extensible Markup Language)** — формат сериализации определения задачи Task Scheduler.
- **DACL (discretionary access control list)** — список разрешений доступа Windows.
- **POSIX (Portable Operating System Interface)** — семейство интерфейсов Unix-подобных систем.
- **CLI (command-line interface)** — интерфейс командной строки. **API (application programming interface)** — программный интерфейс приложения.
- **Handle** — удерживаемый дескриптор конкретного объекта операционной системы; имя файла само по себе им не является.
