Связывание проверено чтением полного изменения и сборкой; отдельный тест, повторяющий восемь присваиваний указателей, в изменение не включён.

## Удаление семи исключений

У каждого из семи удалённых блоков baseline совпадает идентификатор с исчезнувшим вызовом конструктора из таблицы 2. Для `realManifestViewer.ManifestGet` исключения в baseline не было: его удаление уменьшает `New` на один. Остальные семь удалений уменьшают физический долг, ранее покрытый исключениями.

Полный baseline не генерировался заново. Не добавлены новые исключения, не перенесены идентичности к другому коду, не продлены сроки и не подняты допустимые метрики. `owners.yaml`, `policy.yaml` и `workers.yaml` совпадают с исходным head PR. Изменение не принимает оставшийся долг.

Для всех 2403 оставшихся блоков подтверждено полное совпадение исходных байтов. Сохранён и 84-байтовый заголовок, включая `schema_version` и `generated_from=1b875e3ad9f0ca7d4bc306edb6c22431b66da6c7`. Его SHA-256: `70f6aceea00af46c5ffcf57ac1748606dabbadaad962039f34836f8021fd8b03`.

Совокупная SHA-256 оставшихся блоков: `54b111bc95ec9cfb828b3ed9fefc7e66b166cef317c1fdb061dd5f23d7cc22b4`. Для её воспроизведения блоки упорядочиваются по fingerprint; для каждого записывается строка `fingerprint`, пробел, SHA-256 исходного блока и перевод строки LF. В [results.json](results.json) перечислены все восемь исчезнувших fingerprint, семь соответствующих хешей удалённых блоков и их размеры. Полные удалённые байты присутствуют в `architecture.patch` внутри архива доказательств.

Ключевые записи архива:

- `architecture.patch` — ровно проверенная правка двух исходных файлов.

Для проверки самого архива достаточно стандартной библиотеки Python. Следующая команда, запущенная из каталога с архивом, проверяет его идентичность, инвентарь и все исходные байты без распаковки, запуска Go и сетевых обращений:

```python
from pathlib import Path
import hashlib
import json
import zipfile

path = Path("manifest-services-evidence.zip")
data = path.read_bytes()
assert len(data) == 218111
assert hashlib.sha256(data).hexdigest() == (
    "5f1e0c3221aae6cd9bac45e84560dbb4733f02134c49b82cf53438eb90f03c05"
)
with zipfile.ZipFile(path) as archive:
    assert archive.testzip() is None
    manifest = json.loads(archive.read("manifest.json"))
    names = archive.namelist()
    assert len(names) == len(set(names)) == 53
    assert set(names) == set(manifest) | {"manifest.json"}
    for name, expected in manifest.items():
        payload = archive.read(name)
        assert len(payload) == expected["bytes"]
        assert hashlib.sha256(payload).hexdigest() == expected["sha256"]
print("Archive identity and all 52 payload entries verified")
```

Проверка сохранённых байтов не является повторным выполнением тестов. Для квалификации иного исходника нужно отдельно материализовать его точную композицию и повторить затронутые проверки.

## Термины и сокращения

- **API (Application Programming Interface)** — программный интерфейс; здесь также имя Go-пакета и типа `api.API`, реализующего операции приложения.
- **GUI (Graphical User Interface)** — графический интерфейс пользователя; здесь HTTP-обработчики веб-интерфейса сервера.
- **HTTP (Hypertext Transfer Protocol)** — протокол запросов и ответов веб-интерфейса.
- **PR (Pull Request)** — запрос на включение изменений в GitHub.
- **Baseline** — перечень существующих архитектурных исключений с владельцами, сроками и предельными метриками.
- **Fingerprint** — стабильный контрольный идентификатор конкретного архитектурного нарушения.
- **Gate / архитектурный барьер** — обязательная проверка допуска; здесь полная команда `archcheck verify`.
- **Receipt / квитанция** — сохранённые сведения о конкретном запуске, его исходе и контрольных суммах вывода.
- **SHA-256 (Secure Hash Algorithm, 256 бит)** — криптографическая контрольная сумма байтов.
- **JSON (JavaScript Object Notation)** — структурированный текстовый формат результатов и событий тестов.
- **LF (Line Feed)** — перевод строки, используемый при расчёте совокупной контрольной суммы блоков.
- **МСК** — московское время, UTC+3.
- **UTC (Coordinated Universal Time)** — всемирное координированное время.
