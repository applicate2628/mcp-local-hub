Для **всех 2712** публичные байты совпадают с исходными; замен частных значений в этом срезе не потребовалось. Встроенный `_package/manifest.json` хранит размеры и исходные/публичные SHA-256 каждого входа; `_package/summary.json` связан собственным хешем. Размер ZIP, CRC, состав и каждый входной хеш независимо пересчитаны после переноса.

Архив исходных описаний содержит точные UTF-8 тела всех 31 PR, метаданные и встроенный манифест, всего 64 элемента. Старые тексты не выброшены при сокращении. Поле `base_sha_reported` в исторических метаданных не используется как доказательство текущей вершины базовой ветки. [Внешний манифест исходных описаний][original-manifest] также сохранён.

[Материалы статического разбора][reviews-zip] содержат исходные заключения, включение и небольшие патчи. Их PENDING/NOT_RUN относятся к моменту подготовки; фактическое продолжение фиксируют таблицы 1–3 и квитанции этого каталога. Большие рабочие копии Git в публикацию не включены.

Для проверки скачанного runtime-архива без извлечения и без исполнения продукта используется [автономный проверяющий скрипт][verifier]:

```sh
python3 verify_public_archive.py runtime-evidence.zip --expected-sha256 099f6b1a26cb99e87fc765ad9ef54370510e06d5c951e91ac4a3472dddc7500d
```

Он проверяет состав/CRC/хеши, связывает кандидатные файлы и исходные наблюдения с манифестами и заново считает результаты из JSON-потоков всех 11 тестовых команд. [Фактический результат независимого расчёта][verify-result] совпал с таблицей 2. Это проверка целостности и внутренней согласованности свидетельств, а не криптографическое удостоверение исполнения на конкретном компьютере. Без отдельно доверенного хеша файл и его манифест можно заменить вместе.

Повторно использован неизменённый захватчик R21; старые поля его initial receipt остаются историческими. Принадлежность R24 устанавливают конечные scope-поля, закреплённая обвязка, база/дерево и манифест overlay. Хеши исполняемых инструментов в прежних квитанциях не являются новым снимком инструментов во время упаковки. Ожидание прямого дочернего процесса ограничено; завершение и срок всего дерева потомков не доказаны.

## 6. Оставшиеся границы

Общая программа остаётся открытой. [План][plan] сохраняет конкретные входы для следующих работ:

1. Нативный Scheduler: результаты завершённых действий, состояния, владельцы/права, начавшаяся отмена, срок дерева процессов, Run/RunOwned/Stop и производственный Delete.
2. Установка и восстановление: сквозной сценарий, внешняя замена, неопределённый prune, прежний принудительный ImportXML, права/пароли, расписания и срок хранения снимков.
3. R16 и измерения: реальные нагрузки, бюджеты, командная строка и родитель процесса, оставшиеся отказы наблюдения/RAM, потребители CMake/Relay, параллельность и удержание результатов.
4. Rust и reader #627: настоящий потребитель владельца, capability/custody/SID и проверенные байты 11 отсутствующих в ограниченном наборе локальных хранилищ зависимостей. Их глобальное отсутствие не доказано. Параллельные ожидание/закрытие сначала сопоставляются с фактически предоставленным исходником.
5. Общие Go-критерии: квалифицированные Product/entrypoint/Serena-входы, объяснение бюджета API/CLI и оставшихся отказов. Успешные адресные тесты не заменяют прежний общий FAIL.
6. Продуктовые и платформенные границы: полные #648/#652, новый source-issued publisher, 14 миграционных сценариев, Relay, Unix ARM64 и установленный продукт.
7. Внешнее ревью конкретных опубликованных коммитов и дальнейшее сокращение очереди только при доказанном сохранении полезного остатка.

Новых установок или изменения политики для обхода этих границ не выполнялось. Ограничение effective PowerShell policy остаётся UNKNOWN после прежнего сбоя чтения; точечные успехи его не снимают.

Два первоначальных отказа нативного переименования (87 и 5) сохранены; их причины не объявлены доказанными. Успешное перемещение через файловую операцию выполнено после закрытия всех дескрипторов помощника. Подробности — [cleanup.json][cleanup].

Все удалённые записываемые каталоги находятся в `D:\dev\ChatGPT`. Существующие инструменты использованы без установки. Зависимости не скачивались; ручные CI, изменение системной политики, установленного продукта, задач планировщика и полномочий не выполнялись. Сборки и тесты запускают только предварительно просмотренный выбранный scope. Отсутствие командных сессий само по себе не доказывает отсутствия всего дерева процессов.

API/CLI — программный интерфейс/командная строка; CI — непрерывная интеграция. EOF — конец потока, I/O — ввод/вывод, TCP — транспортный протокол, RAM — оперативная память. SID — идентификатор безопасности Windows; custody — непрерывное владение исходным ресурсом; capability — выданное владельцем полномочие. Publisher — построитель и издатель квалифицированного исполняемого образа; source-issued — связанный с конкретным исходником. MCP — Model Context Protocol, протокол взаимодействия модели с инструментами.
