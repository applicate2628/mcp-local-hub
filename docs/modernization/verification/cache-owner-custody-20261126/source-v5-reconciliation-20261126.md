## 4. Исполнение POSIX и Unix на ARM64

[Точный Go reader #668](https://github.com/applicate2628/mcp-local-hub/blob/1b7655ae9a0dec7d6821d8419087fd92ccadbb62/docs/modernization/verification/go-reader-close-errors-20261122/README.md) имеет 30 PASS с детектором гонок Windows и успешную компиляцию Linux/amd64 на `8588129` с 13 подменами. Тестовый двоичный файл Linux не исполнялся. Отказ реальных операций метаданных и закрытия средствами ОС остаётся отдельным критерием.

Существующая Ubuntu WSL2 запущена и имеет архитектуру x86-64. В ней проверены Go 1.26.8 и 1.26.4 для Linux/amd64, `gofmt` и прямые исполняемые файлы Rust и Cargo 1.100.0. Минимальная версия Go нового Test Source — 1.26.2. В существующем кэше Go обнаружены архивы, включая три прямые зависимости из `go.mod`. В отдельной изолированной копии точного #668 теперь подтверждён **PASS исполнения Linux/amd64**. Стандартная команда и команда с тегом `test_state_path_env` дали по 5 корневых PASS, 15 подтестов PASS и PASS пакета, без пропусков. Подтверждены завершение обоих Linux-деревьев, исходные журналы и неизменность исходников. Исторический `NOT_RUN` остаётся статусом исходной Windows-квалификации. [Отчёт исполненной проверки](posix-runtime-20261126.md) и [машиночитаемая квитанция](posix-runtime-20261126.json). [Источник 9](#6-источники-и-контрольные-суммы).

На двух проверенных Linux-средах наблюдалась архитектура x86-64. В Ubuntu WSL2 не обнаружены `qemu-aarch64`, `qemu-aarch64-static` и регистрация исполнения ARM64 через `binfmt_misc`. Исполнение Unix/ARM64 остаётся `NOT_RUN`. [Источник 9](#6-источники-и-контрольные-суммы).

Сохранённый `launch_literal_final_v13.py` привязан к ACA и завершившемуся `runs/literal-final-v10`. Команда `literal-state` отсутствует в списке выданных команд. На момент последнего чтения родительская квитанция оставалась `running` без полученного кода выхода и подтверждения закрытия потоков.

В дочерней квитанции удержан `internal/api/zz_qualified_api_versioninfo_windows_amd64.syso`. ## Термины и сокращения

- **Source** — физический снимок исходников, привязанный к коммиту и полному перечню файлов. **Test Source** — снимок для сборки и исполнения тестов.
- **Product** — принятый исполняемый комплект. **V1** — рабочая версия формата его идентичности.
- **Default / tagged** — тестовые наборы без дополнительных тегов сборки и с тегом `test_state_path_env`. **Go vet** — статическая проверка кода.
- **API** — программный интерфейс. **CLI** — интерфейс командной строки. **POSIX** — стандартизованные интерфейсы Unix-подобных систем. **WSL2** — подсистема Windows для Linux второго поколения. **ARM64** — 64-разрядная архитектура ARM.
- **SHA-256** — 256-разрядная контрольная сумма исходных байтов. **PR** — запрос на включение изменений.
