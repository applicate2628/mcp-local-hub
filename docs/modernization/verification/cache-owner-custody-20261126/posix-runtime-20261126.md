## Термины и сокращения

- **POSIX** — стандартизованные интерфейсы Unix-подобных систем. **amd64** — 64-разрядная архитектура x86. **ARM64** — 64-разрядная архитектура ARM.
- **WSL2** — подсистема Windows для Linux второго поколения. **JSONL** — отдельная запись JSON на каждой строке.
- **`pidfd`** — файловый дескриптор, удерживающий идентичность процесса Linux. **`ECHILD`** — результат системного вызова ожидания, когда дочерних процессов больше нет.
