## Что обнаружено в исполнителе

В проверенном guard `56d6…` обычные команды и внешние контроллеры используют разные пути. Внешняя named/deferred-ветка `GuardedRun.command` по-прежнему вызывает `subprocess.run(timeout=…)`. При его тайм-ауте Python завершает прямой дочерний процесс и ждёт его выхода; затем распространяет `TimeoutExpired`. В этой ветке исходный `Popen` не сохранён в реестре обычных владельцев, а файловые контексты закрываются при выходе по исключению. [5,6]

Текущий получатель позднего физического завершения умеет работать только с сохранённым обычным Windows Job owner. Для внешней строки `suite-owner` такого объекта нет. Сохранение Python-объекта Invocation само по себе не восстанавливает владельцев, находившихся внутри Go-контроллера. Поэтому этот отказ не превращается в CLOSED по уже имеющемуся контракту. Это дефект сохранения владения; причина длительности самого CLI-набора пока не установлена. [5]

Прежние 14 нативных сценариев и две проверки композиции остаются действительными в своих проверенных границах. Они не доказывают поведение внешнего контроллера при тайм-ауте. Исправление должно охватывать обе стороны: сохранение исходного Python-процесса и запрет потери исходных объектов при выходе самого Go-контроллера. Активная неудачная попытка не изменяется задним числом. [3,5]

## Сохранность ресурсов

Пять подтверждённо закрытых объектов перенесены в отдельный trash с журналами PREPARED → MOVED и теми же native/stat идентификаторами: частичная Source4 и build/module-кэши завершённых startup/provider-проверок. Исполняемые образы, исходники проверок, квитанции и данные восстановления оставлены вне trash. Trash не очищался. [4]

В новой области UNKNOWN сохраняются v11, его исходники Source5, временные данные, кэши, дочерняя область CLI, родители доказательств d11/s11 и оставленный `.syso`. Последующие наблюдения исходников, хешей входов и автоматическое освобождение ресурсов не выполнялись. Исходная старая область v7/x6d и её UNKNOWN также сохранены. Содержимое захватов неизвестно завершившихся команд не читалось. [5]
