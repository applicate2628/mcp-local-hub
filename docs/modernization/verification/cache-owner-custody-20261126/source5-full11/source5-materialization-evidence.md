## Принятый результат

В свежей области `native-consumer-source-v5` воспроизведён тот же Product commit `3ebe335a2f666a5279d7fafc31a6f4dc3feedff4` с родителем `c3b8c802be190c335b84ff7323a14d9eb63518b6`. Карта содержит **3508 файлов**; её исходный SHA-256 — `671d60c8f1e96de28eb616b9e7aeacccae50d00359ab27a59418bea61648ee16`. До применения прежних диагностических изменений родительская карта содержала 3505 файлов. Различаются 15 путей; это реконструкция прежнего Product, а не будущая правка 13 тестовых файлов. Обе полные карты в исходной записи равны отдельно сохранённым картам. [2,3,5,6]

Родитель получил завершение исходного процесса с кодом 0 за **108.900 с** и закрыл оба собственных файла вывода. Все **14 команд** завершены с кодом 0: исходные процессы получены, дерево процессов пусто, дескрипторы закрыты. Все **28 потоков ввода-вывода (stdout/stderr)** достигли конца данных, их файлы закрыты и исходные читатели завершены. Два файла вывода родителя учитываются отдельно от этих 28 потоков. Число и порядок команд, активный план, код исполнителя и все 26 закреплённых входов согласованы. [1–4]

Нативная приёмка подтверждает чистое рабочее дерево и неизменность исходных входов и донора. Её допуск ограничен неизменяемыми отслеживаемыми исходниками: он сам по себе не выдаёт права на кеши, очистку, тестовый запуск, установку или готовность продукта. [2,3]

`checkout-c3` завершился за **1,921 с** с тем же рабочим пределом **120 с**. В прежнем Source4 он превысил этот предел и был закрыт за **120,032 с**. Задержка в новом запуске с Git Trace2 не воспроизвелась. **Причина прежней задержки неизвестна**; наблюдение не доказывает исправление производительности, влияние антивируса или иной механизм. Локальная копия stderr checkout проверена по исходным байтам: 9041 байт, SHA-256 `549899c432ebcbe4d11af7cc25e8fb40fc9fcf7cfbb08cbf33dd1ffc49428884`. [2,4,8–10]

Source4 сохраняет **CLOSED_FAIL**: три исходные команды и шесть потоков закрыты, родитель получил код 1. Отдельная принятая проверка данных Source4 v2 обнаружила **3392 имеющихся и 113 отсутствующих файлов** относительно базы из 3505; лишних файлов и несовпадений содержимого среди прочитанных — 0. Управляющие файлы Git до и после наблюдения совпали. Это наблюдение незавершённого checkout, а не допуск Source4 к использованию и не установление причины тайм-аута. Прежняя проверка данных со статусом `INCOMPLETE` сохранена. [9–12]

Независимое ревью Source4 v2 приняло именно наблюдение данных. Отдельная локальная запись родителя этого postmortem-процесса не предоставлена: его код 0 сообщён нативной приёмкой root, но не подтверждён здесь отдельной связкой хешей процесса. Эта граница не относится к закрытию исходных трёх команд Source4, которое подтверждено исходными parent/receipt. [9–12]

Автор этого черновика выполнил локальную проверку точных исходных файлов, связок parent → receipt → root, всех 14 записей закрытия, 28 потоков, двух полных карт и независимого ревью. SHA-256 вычислен по исходным байтам без преобразования переводов строк. JSON разобран Python с точными целыми числами; 64-разрядные идентификаторы объектов не экспортированы в компактную проекцию, а исходники не пересериализованы. [1–12]

Физические файлы Source5 автор повторно не читал. Из raw captures локально перепроверен только `checkout-c3.stderr.txt`; приёмка остальных опирается на точный нативный root и согласованные метаданные, а не на заявленный повторный замер всех 28 файлов. Новых удалённых действий, нативных запусков, повторов квалификации Serena или 14 случаев владения процессами здесь нет. Основной план и оперативные исходники/runtime не изменены. [3,4,7,8]
