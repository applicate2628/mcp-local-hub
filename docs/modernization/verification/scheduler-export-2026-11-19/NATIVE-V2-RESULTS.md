## 3. Приёмка семи чтений

В `result.json` V2 записаны `reads_passed=true`, `cleanup_complete=true`, `error=null`. Массив `checks` содержит ровно семь проверок в порядке таблицы 3. Массив `children` содержит те же семь меток, и для каждой выполнены `settled=true`, `exit_code=0`. Это результат новой попытки; пустой `checks=[]` первой попытки не заменён и не переоценён задним числом. [Квитанция V2 (2026/11)](native-v2-evidence.json), [исторический результат (2026/11), §1](NATIVE-RESULTS.md#run).

**Таблица 3. Выполненные проверки и критерии PASS.** Критерии следуют из [точного сценария (2026/11)](Invoke-R17HiddenFixture.ps1); выполнение каждой проверки записано в [квитанции V2 (2026/11)](native-v2-evidence.json).

| № | Проверка | Принятый результат |
|---:|---|---|
| 1 | `status-visible` | `ok=true`; точное имя видимой задачи, состояние `1` — Disabled, полное XML из снимка успешной регистрации и исходный принципал |
| 2 | `export-visible` | Те же имя, отключённое состояние, точное XML и принципал видимой задачи |
