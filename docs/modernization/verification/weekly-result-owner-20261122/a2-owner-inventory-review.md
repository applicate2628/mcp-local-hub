Чтением всех обычных импортов `github.com/gofrs/flock`, мест вызова и

об исполнении типизированного инвентаря. Этот подсчёт нельзя переносить на
квалификационную композицию с дополнительными производственными заменами.

Реальный запуск публикационного перечня на этой расширенной композиции дал
FAIL на `AcquireSupervisorLockQuietObserved`; квитанция не заменяется
успешной. Для повторной квалификации создана отдельная копия
`inputs/a2-composition/internal/api/supervisor_intent_lock_ownership_test.go` в [сыром архиве](raw-evidence.zip).

по одному вызову** для владельцев выше. Начальная сумма этой копии до
форматирования —
`d5b22597fc78a9304ac9c630adb759932cd430afae7568e241a5812eff853e47`,
18685 байт. Основной файл с 28 записями не менялся. Матрица фикстур,
отказ неизвестным владельцам, отрицательная проверка соседнего
классификатора и алгоритм инвентаризации в отдельной копии сохранены
побайтово. Фактический результат последующего исполнения адаптации сохранён в
[итоговом отчёте](README.md#4-все-фактические-результаты) и отдельной квитанции
владельца квалификации внутри сырого архива.

## Назначение и жизненный цикл двух добавленных владельцев

`acquireStateFileObservedLease` [2] получает внутрипроцессную блокировку
`ledgeredLeafGate`, проверяет реестр неподтверждённого освобождения и создаёт
один `flock.Flock` для `supervisorIntentLockPath`. Получение выполняется через
`TryLockContextObserved`. Неудача направляется в `CloseObserved`; закрытие
проверяет поколение и исходные результаты, записывает ошибку через
`recordUnconfirmedLockRelease`, затем освобождает внутрипроцессную блокировку.
Активный `Borrow` откладывает закрытие до выхода последнего заимствования.
Перечень учитывает единственный конструктор в строке 103.

`(*secretsInitRecoveryOwner).locked` [3] сериализует резервирование и
завершение записей восстановления secrets-init через
`secrets-init-recovery.lock`. После одного конструктора в строке 531 он
вызывает `Lock`, при успехе устанавливает отложенное освобождение и выполняет
переданную операцию.

**Отдельный существующий дефект для остаточного плана B:** строка 535
содержит `defer func() { _ = lock.Unlock() }()`. Если `Unlock` возвращает
ошибку, `locked` всё равно возвращает результат `fn`; при `fn() == nil`
вызывающий получает успех. Ошибка освобождения не передаётся и не записывается
в реестр неподтверждённых освобождений. Это свойство существующего
производственного кода, не внесённое A2. Допуск точного владельца в перечень
подтверждает местоположение конструктора; он **не является квалификацией
безопасности освобождения**. Производственный код здесь не исправлялся.
