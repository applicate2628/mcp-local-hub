## Terms and Abbreviations

- **API**: application programming interface; here, also the repository's API test package.
- **CLI**: command-line interface and its test package.
- **Git tree**: the object that binds file names, modes and blob identities for a repository snapshot.
- **SHA-256 / SHA-1**: hash algorithms used here to check artifact bytes and historical Git object identity, respectively.
- **PASS / FAIL**: the recorded result of a specified operation, not a whole-project verdict.
- **CLOSED**: original owned processes and input/output resources were received as physically settled.
- **NOT_RUN / UNKNOWN**: not executed, or not sufficiently established; neither is a PASS.
- **DATA check**: inspection or hashing of existing artifacts without executing their preserved code or tests.
- **Source / Product**: tracked repository bytes at a commit, and a built application bundle, respectively.
- **PR**: pull request, the existing repository review and publication destination.
