# Исправления по аудиту, 25.11.2026

## Область и маршрут

Продолжение единого [плана PR](open-pr-integration-20261117.md). Все 32 текущие публичные вершины сверены: изменений после аудита нет. Пользователь разрешил исправления и публикацию результатов в существующие PR; слияния запрещены. Исходный аудит остаётся историческим срезом, не свидетельством выполнения новых проверок.

1. Независимые исправления на исходных ветках и перенос уже готовых изменений.
2. Одна согласованная композиция зависимых владельцев.
3. Точные регрессии, обязательные общие проверки и приёмка фактических сценариев.
4. Независимое ревью, безопасная публикация в существующие PR, актуализация остатка.

## Термины и сокращения

PR — запрос на включение изменений; MCP — Model Context Protocol; SID — необязательный идентификатор транспортной сессии; PID — числовой идентификатор процесса; delta — конкретная разница исходников.
